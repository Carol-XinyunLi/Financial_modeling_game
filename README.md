# Financial Modeling Game - NPLB Terminal

An interactive pharmaceutical drug development investment simulator. Manage a biotech fund's portfolio through clinical trial phases and FDA approval.

## How to Play

1. Enter your fund name and starting capital
2. Click "Display Drugs Available to Investor" to deal 10 random assets
3. Each round, select which drugs to fund for the next phase
4. Resolve clinical trial outcomes (with random success/failure)
5. Submit approved drugs to the FDA
6. See your final portfolio performance and impact metrics

## Features
- Realistic clinical trial phase progression (Phase 1 → 2 → 3 → FDA)
- Probabilistic outcomes with NPV uncertainty reduction
- Capital management constraints
- Real-world disease indications and drug modalities
- Summary dashboard with ROI and lives impacted metrics
